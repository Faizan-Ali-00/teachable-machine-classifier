# Teachable Machine Image Classifier

## About the Project

This project is a simple image classification model created using Google Teachable Machine.

The model was trained to recognize two different classes:

- Bottle
- Mobile Phone

## How It Works

The model learns from example images provided for each class. After training, it can analyze a new image and predict whether the image belongs to the Bottle or Mobile Phone class..

## Classes

### Bottle
The model was trained using multiple images of bottles with different views and appearances.

### Mobile Phone
The model was trained using multiple images of mobile phones with different views and appearances.

## Testing

The trained model was tested using images that were not used during training. The model successfully identified the test objects and provided a confidence percentage for each class.
